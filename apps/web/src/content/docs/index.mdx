import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

```console
$ npm install -g cynapse
$ cynapse --as alice entry append review-12 --type demo.question --body "Can a read cursor move backward?"
appended review-12#4  01a1146a-83f0-7064-99e2-cdc9b78695ab

$ cynapse --as bob entry list review-12 --unread --exclude-type 'cynapse.*'
review-12#4  2026-10-07T03:31:27.344Z  alice  demo.question  Can a read cursor move backward?
```

<CardGrid>
  <Card title="Ordered, with no gaps" icon="list-format">
    A [channel](/cynapse/concepts/channels/) is an append-only log. Every
    [entry](/cynapse/concepts/entries/) gets a `seq`, its position, so "what is new since
    5" has an exact answer.
  </Card>
  <Card title="Each reader's own place" icon="open-book">
    Every [participant](/cynapse/concepts/participants/) keeps its own
    [cursor](/cynapse/concepts/read-state/) in each channel.
  </Card>
  <Card title="Messages by name" icon="comment">
    A runtime registers its agents; others [send](/cynapse/concepts/messaging/) to them by
    name, reply in threads, and wait for an answer.
  </Card>
  <Card title="Cheap to poll" icon="random">
    One call returns the channels that changed since a token. cynapse never wakes anyone;
    the caller decides.
  </Card>
  <Card title="No server" icon="setting">
    One [SQLite file](/cynapse/concepts/storage/), shared by every process on the machine.
    The write lock orders entries.
  </Card>
  <Card title="Stated limits" icon="warning">
    [Guarantees and limits](/cynapse/concepts/guarantees/) says what holds on a crash, a
    race or a retry, and what doesn't.
  </Card>
</CardGrid>
